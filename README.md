# Backend API – Node.js / Express

Production-ready REST API with authentication, sessions and CI/CD.

## 🚀 Live Demo
- API: https://integrador-53155-production-1059.up.railway.app
- Docs: https://integrador-53155-production-1059.up.railway.app/api/docs

## 🧱 Tech Stack
- Node.js + Express
- MongoDB + Mongoose
- Passport (Local + Google OAuth)
- Sessions stored in MongoDB
- Docker + Docker Compose
- GitHub Actions (CI)
- Railway (Deployment)
- Swagger (API Docs)

## 🔐 Authentication
- Register / Login
- Google OAuth
- Session-based auth with cookies
